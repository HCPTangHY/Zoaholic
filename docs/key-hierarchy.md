# 渠道批量管理与母子 Key

## 渠道批量管理

渠道页面继续使用现有 `groups` 筛选，一次选择一个组。默认浏览时不显示渠道复选框，点击筛选栏中的“选择”进入选择模式；此时可以全选当前筛选结果，包括折叠的渠道。取消选择模式会清空选择。仅保留列表内部原有的风琴折叠，不再增加整表折叠入口。

选中渠道后显示启用、停用和复制配置操作；手机上使用底部操作栏。启停操作直接确认目标，复制配置先选择源渠道和字段，再确认目标。目标名单与配置摘要可以展开查看，保存结果分别列出成功数量和失败原因。

复制操作分为冷却与 Key Rules、模型合并、模型替换。模型合并遇到相同上游模型名称时保留目标映射。复制前展示源配置和目标渠道，不复制 URL、Key 或分组。源中未配置的冷却兼容字段会从目标中移除。

批量保存逐渠道执行，失败会列出对应渠道，不保证整批回滚。操作期间请勿在其他窗口同时编辑这些渠道。`groups` 仍是访问范围，不是纯展示标签。

## 母子关系

每个 Key 都可以调用 API，并可通过 `parent_id` 指定一个上级的 `id`。支持多层，但不允许循环、重复身份或引用不存在的上级。

```yaml
api_keys:
  - id: team
    api: zk-example-parent
    name: 团队
    groups: [default]
    model: [model-a, model-b]
    preferences:
      quota:
        token: 1000000/day:fixed
  - id: member-a
    parent_id: team
    api: zk-example-member-a
    name: 成员 A
    preferences:
      quota:
        token: 100000/day:fixed
  - id: member-b
    parent_id: team
    api: zk-example-member-b
    name: 成员 B
```

示例凭据不可用于生产。管理员应使用生成按钮生成随机凭据；在母 Key 的操作栏选择“创建子 Key”即可新增一个独立凭据。

`id` 接受 1–191 个英文字母、数字、下划线或连字符。旧配置自动获得稳定 ID；修改凭据时保留 ID。名称和数组顺序不参与关系识别。

### 继承和权限

- `api`、`id`、`parent_id`、`name`、`role`、`enabled` 不继承。管理员权限不会自动传给子 Key。
- 普通配置按字段继承，`preferences` 内部按字段继承；列表和一个字段内部的对象整体覆写。
- 子 Key 没有填写的字段跟随上级变化；取消覆写后恢复继承。
- 显式 `0`、`false` 和空列表不等于缺省。`model: []` 或 `groups: []` 表示没有相应授权；要允许全部模型，请填写 `model: [all]`。
- 子 Key 可以配置超出上级的范围，但请求必须满足所有祖先的权限，超出部分不能调用。
- 管理界面展示的“生效值”是继承合并后的配置，不是权限交集清单。模型列表与实际路由会进一步应用整条祖先链限制。
- 上级停用会阻止整个下级分支。仍有下级时不能直接删除上级，需先迁移或逐层删除。

### 额度和统计

沿用 `preferences.quota`、`quota_rules` 和旧额度兼容格式。当前 Key 和所有上级都必须有剩余额度。子级耗尽不影响母级和其他分支；母级耗尽影响全部下级。

请求次数先检查整条链，再统一记录。Token 和费用按请求结束时的实际值结算，各级各累计一次，全局累计一次。并发和流式请求可能产生少量超额，没有引入额度预留。

每次请求只记录实际调用者的一条日志，同时保存稳定身份及请求时的祖先 ID。可查看直接调用或包含下级的分支汇总，两者不能再次相加。迁移只影响后续请求。旧日志没有祖先信息，不能追溯生成迁移前的分支归属。

删除身份后不再保留其运行时额度计数器；已完成或仍在途请求的历史日志仍保留原身份。固定窗口、永久 Token/费用额度支持快照恢复；有限滑动窗口沿用原有重启语义。

管理员用量接口：

```
GET /v1/stats/usage_analysis?api_key_id=team&key_scope=branch&hours=24
```

`key_scope` 可为 `direct` 或 `branch`，可从 Key 列表的统计入口查看。编辑面板不展示历史用量。

编辑面板先显示名称、凭据、角色及所属上级，再显示权限和额度。每项策略旁提供继承状态与独立配置切换。继承时显示上级值并禁止编辑；切换独立配置时以当前继承值初始化，恢复继承后不再保存该字段的覆写。额外配置的 JSON 编辑位于底部高级设置中。

不提供批量创建子 Key 或批量导出接口。网络响应中断时先刷新列表核对是否已创建。

## 部署注意

本功能为请求统计增加 `api_key_id` 和 `key_ancestor_ids` 两列，沿用启动时的表结构迁移。升级前备份配置和数据库。

没有增加自行领取、OAuth 身份联动、多分组同时展示或严格额度预留功能。文件与数据库双写不是分布式事务；存储故障时应核对两端，不应把接口失败直接视为两端都没有改变。
